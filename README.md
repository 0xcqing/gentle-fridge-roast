A one-line smart fridge roast for the [make.fun](https://make.fun) Fridge Roast competition.

## Entry

The program writes a single-line roast to `/output/entry.txt` at runtime. The roast is exactly one line, under 200 characters, roasting a smart fridge.

## Running

```bash
node main.ts
```
